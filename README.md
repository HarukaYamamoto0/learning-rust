# Learning Rust

Here lie my experiments and little projects that I make while learning Rust.

This repository probably has no practical use for anyone else. I mostly keep it here so GitHub can keep a record of my progress, and so it doesn't look like I've been doing absolutely nothing while learning Rust.

I'm currently following the [Rust Book](https://doc.rust-lang.org/book/), going section by section and learning at my own pace. Of course, I also end up making random things along the way, like a small configuration file reader for simple `.env`-style files.

But overall, I'm trying to stick to the Rust Book and learn the language properly, one section at a time.

I love Rust ❤️.
